# 噪音提示（网页版 / PWA）

无需 Mac、无需安装 App，把本文件夹托管到任意 HTTPS 静态网站后，iPhone 用 Safari 打开即可使用。检测算法与 PC 版一致（低频 45–200 Hz 频带分析 + 自适应背景基线 + 防误触状态机），实时性更好，因为音频处理全部在本机完成，不上传任何声音。

## 使用方法

### 第一步：把本文件夹放到网上（任选一种）

- **Netlify Drop（最简单）**：打开 https://app.netlify.com/drop ，把整个 `web版` 文件夹拖进去，几秒后得到一个 `https://xxxx.netlify.app` 的地址。
- **GitHub Pages**：新建仓库 → 上传本文件夹 → Settings → Pages → 选择分支，得到 `https://用户名.github.io/仓库名/` 的地址。
- 其他任意 HTTPS 静态托管（Cloudflare Pages、Vercel 等）都可以。

> 注意：必须 HTTPS 才能使用麦克风（iOS 的安全要求）。直接用 `python -m http.server` 开的 HTTP 本地服务在 iPhone 上无法使用麦克风。

### 第二步：在 iPhone 上使用

1. Safari 打开该地址，第一次点「开始监听」时允许麦克风权限。
2. 建议「分享 → 添加到主屏幕」，以后从主屏幕图标进入，像 App 一样全屏使用。
3. 保持页面在前台、屏幕常亮（页面会自动请求屏幕唤醒锁；部分 iOS 版本需在“设置 → Safari → 自动锁定”里调长）。

## 界面功能

- 两种模式：**低音冲击**（默认，抓脚步/敲击）和**普通音量**
- **报警音频自选**：点「选择文件」上传 mp3 / wav / m4a，触发时播放你选的音频；也可用 4 种内置音（叮咚、蜂鸣、短促滴、钟琴）
- **确认次数（N 次 / T 秒）**：每越过阈值就立即记一次冲击（无安静间隔，连续脚步、快速敲击都能逐个计入），在 T 秒窗口内累计到 N 次才播放，避免单次误触发
- **冷却时间**：播放后才开始计时，期间不再累计，冷却结束清零、重新计数，防止连播
- **抗误触发**：要求低频明显强于中频和高频（说话声中频更强，会被拒掉）；峰值回落 + 最小事件间隔 + 固定计数窗口，避免同一声响被重复计数、累积来回跳动
- **灵敏度**：低频能量高出环境背景多少 dB 算一次冲击，越小越灵敏
- 高级参数：麦克风增益
- 设备：可切换输入设备（麦克风），切换后自动重启生效；iPhone 通常只有一个内置麦克风，此时切换不改变实际设备；输出方向由系统控制
- 实时状态面板：低频能量、尖锐度、冲击累积（2/3）、低频占比、综合评分、触发次数、运行时长
- 提示音播放期间自动忽略麦克风，防循环

## iOS 网页版的重要限制

| 项目 | 网页版 | 原生 App（需 Mac 或云编译） |
| --- | --- | --- |
| 后台/锁屏监听 | ❌ 切后台或锁屏会暂停 | ✅ 支持（需后台音频权限） |
| 蓝牙音箱输出 | ✅ 走系统当前输出 | ✅ |
| 部署难度 | 极低，零成本 | 需要构建 + 签名 + 每 7 天重签 |

如果必须锁屏后持续监听，网页版做不到（这是 iOS 对网页的硬性限制），需要用原生 App 方案（见主目录 `iOS版/` 和根 README）。

## 本地开发调试

在电脑上想快速预览，可用支持 HTTPS 的本地服务器（如 `npx serve --ssl`），手机与电脑连同一 WiFi 后访问 `https://电脑IP:端口`；Safari 提示证书不受信任时选择“显示详细信息 → 访问此网站”即可。
