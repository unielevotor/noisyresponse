# 噪音提示工具

用无线麦克风实时监听环境噪音，一旦出现异常声音（脚步踩地、硬物戳地等），就自动在蓝牙音箱上播放提示音。

内置两种检测模式：

- **低音冲击模式（默认）**：专门检测脚步踩地、硬物戳地这类低频冲击声。程序持续跟踪环境低频底噪，只要低频（45–200 Hz）能量突然高出背景、且低频不比中频弱，就触发——安静环境下轻轻的“咚咚”声也能抓到，普通说话声基本不会误报。
- **普通音量模式**：整体音量超过阈值即触发，适合检测大声响。

```
无线麦克风 ──► 电脑实时采集 ──► 低频冲击/音量超阈值？ ──► 蓝牙音箱播放提示音
                         │
                         └── 冷却 + 重新武装 + 播放期间忽略麦克风（防误触发、防循环）
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `noise_alert.py` | 主程序（图形界面） |
| `alert.wav` | 默认提示音（约 0.55 秒），可替换成自己的 WAV 文件 |
| `config.json` | 自动保存的设置（设备、模式、灵敏度等） |
| `requirements.txt` | Python 依赖 |
| `run.bat` | 双击即可启动 |
| `iOS版/` | iPhone 版完整 Swift 源码工程（需 Mac + Xcode 构建） |
| `web版/` | iPhone 网页版（PWA）：无需 Mac/安装，Safari 打开即用，需 HTTPS 托管 |

## 安装与运行

1. 安装依赖（只需一次）：

   ```
   pip install -r requirements.txt
   ```

2. 把蓝牙音箱和无线麦克风连到电脑，确认 Windows 声音设置里能正常使用。
3. 双击 `run.bat`（或在目录下运行 `python noise_alert.py`）。

## 使用步骤

1. 点「刷新设备」，在「输入设备」里选无线麦克风，在「输出设备」里选蓝牙音箱（选“系统默认”也可以，但建议明确指定）。
2. 在「检测模式」里保持「低音冲击（脚步声/敲击）」。
3. 点「自动校准（3 秒）」：保持安静 3 秒，程序会报告当前低频底噪并设置灵敏度。
4. 点「开始监听」即可。之后一有脚步声或戳地声，音箱就会自动播放提示音。

提示音可以换成你自己的声音：点「浏览…」选择 WAV 文件（16/32bit，单/双声道均可），再点「试听」确认。

## 参数说明

| 参数 | 含义 |
| --- | --- |
| 检测模式 | 低音冲击（脚步声/敲击，默认）或普通音量 |
| 灵敏度（低音模式） | 低频能量要高出环境背景多少 dB 才触发。数值越小越灵敏（4–20 dB） |
| 触发阈值（普通模式） | 整体音量达到该 dB 值才可能触发（-60 最灵敏，0 最迟钝） |
| 最短持续 | 声音需要持续超过该时长（毫秒）才触发。低音模式默认 80ms，普通模式默认 150ms |
| 触发冷却 | 两次触发之间的最小间隔（低音模式默认 0.5 秒） |
| 麦克风增益 | 麦克风声音太小/太大时用来补偿，±30 dB |
| 重新武装（固定） | 触发后要连续安静约 0.2 秒才重新进入待触发状态，防止语音停顿误触发 |

## 常见问题

**为什么设备列表里没有蓝牙音箱？**
先确认音箱已连接且在 Windows 声音设置中可见，然后点「刷新设备」。部分蓝牙设备需要重新连接后才会出现。

**蓝牙音箱是“耳机/音箱（免提）”模式，声音很卡怎么办？**
Windows 会把蓝牙设备分成“立体声（A2DP）”和“免提（HFP）”两个模式。请在声音设置里选**立体声**作为输出；免提模式音质差，而且可能同时占用麦克风通道。

**提示音被麦克风听到，会不会不停循环播放？**
不会。程序在提示音播放期间会忽略麦克风输入，播放结束后再延时 0.3 秒恢复检测，加上冷却和重新武装机制，正常不会循环。

**为什么连续脚步只触发了一部分？**
提示音播放期间（约 0.85 秒）麦克风输入被暂时忽略，这是防循环的必要代价。想要更密集的反馈，可以换一个更短的提示音，并把冷却调小。

**说话声会不会误触发？**
低音冲击模式要求低频能量不低于中频，说话声通常不满足；同时声音需要相对背景有突然抬升，持续声音几秒后会被背景吸收。若仍有误报，可调高灵敏度。

**轻轻的脚步声检测不到？**
把灵敏度调低（如 5–6 dB）；另外建议把麦克风尽量靠近地面或声源——脚步的“咚咚”主要是地板振动，麦克风贴近地面时灵敏度会明显提高。

**提示音想用 MP3 可以吗？**
直接支持 WAV。MP3 可以先用任意转换工具（或格式工厂）转成 WAV 再使用。

**检测好像太灵敏/太迟钝？**
重新「自动校准」一次，或手动调整灵敏度（低音模式）/触发阈值（普通模式）和最短持续；麦克风增益可以在校准后微调。
